# ServerDeck 0.3.7

- В карточке ПО появилась многострочная инструкция для ИИ: где искать новую
  версию и как проверять обновление конкретного экземпляра.
- Добавлена MCP-ручка `software.updates.check` для подготовки проверки приложения
  или ОС и системных пакетов SSH-сервера. Фактическую проверку выполняет внешний
  ИИ; частота задаётся во внешнем задании Codex, например каждые пять минут.
- Задание проверки можно скопировать из интерфейса. Оно не разрешает установку
  обновлений, остановку служб или перезагрузку без отдельного поручения.
- Инструкция переносится вместе с карточкой при зашифрованной синхронизации.
- Сохранена возможность читать и редактировать ранее допустимые карточки
  максимального размера. Поздний ответ при смене профиля или карточки не копирует
  задание для устаревшего контекста.

После установки переподключите MCP-клиент для загрузки обновлённого списка
инструментов: contractVersion 4, 28 инструментов.

Локальный формат базы остаётся 2, пользовательские данные не сбрасываются.
Переносимый зашифрованный формат карточки ПО обновлён до версии 2; форматы
профиля и корневого снимка остались версии 1. Смешанные версии клиентов и прежние
снимки с карточками формата 1 могут остановить синхронизацию с явной ошибкой
неподдерживаемого содержимого. Локальные данные и сохранённые снимки остаются
нетронутыми; автоматической конвертации или удаления нет. Дальнейшие действия
выполняются через существующий явный выбор сохранения локальных данных и
отсоединения/отбрасывания прежнего состояния синхронизации.

Выпуск публикуется из `serverdeck-app/client`; установленная версия 0.3.6 уже
использует этот канал обновлений. Расписание внешнего Codex этим выпуском
автоматически не создаётся.

# ServerDeck 0.3.6

- Разработка клиента переехала в serverdeck-app/client.
- После установки этой версии обновления проверяются в новом репозитории.
- Добавлены Windows/Android синхронизация профилей, зашифрованных credentials и
  карточек ПО, разрешение конфликтов и управление устройствами.
- Локальные данные и версия формата базы сохраняются; SSH-доверие остаётся локальным.

Старый канал unng-lab/serverdeck предоставляет этот переходный установщик с
подписанным каталогом. Ключ подписи обновлений сохранён. Самостоятельная локальная
работа не требует аккаунта; облачная синхронизация требует настроенного сервиса.

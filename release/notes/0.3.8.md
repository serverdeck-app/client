# ServerDeck 0.3.8

- MCP освобождает соединение и серверную сессию после пяти минут без активности.
  Это освобождает слот для другого чата. Выполняющийся запрос не прерывается.
- Следующий запрос в прежнем чате заново проходит авторизацию и инициализацию.
  Мост к Codex остаётся запущенным; ранее выполненные команды не повторяются.
- При освобождении сессии снимается её захват консоли. Установленные приложением
  SSH-подключения и открытые консольные сеансы сохраняются; для нового ввода через
  MCP потребуется повторно получить захват консоли.
- Исправлены ошибочные сообщения AUTH_REQUIRED при исчерпании соединений или
  повреждённом ответе внутреннего протокола, а также завершение моста при
  закрытии клиента и заблокированной записи ответов.

После установки переподключите MCP-клиент, чтобы старые процессы stdio-моста
заменились новой версией с тайм-аутом. Обновлять разрешение MCP не требуется.
При отзыве, замене или истечении разрешения автоматическое восстановление
прежней сессии не разрешается. Лимит одновременных активных соединений остаётся 8;
простаивающие мосты после тайм-аута не занимают эти слоты. MCP ping и уведомления
считаются активностью и сбрасывают таймер простоя.

Форматы базы и синхронизации, а также список MCP-инструментов не меняются.

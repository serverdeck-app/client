# ServerDeck 0.3.12

- На Windows мониторинг автоматически возобновляется при запуске ServerDeck.
  Предупреждение о нештатном завершении убрано, история измерений сохраняется.
- Установщик добавляет ServerDeck в автозагрузку текущего пользователя Windows.
  Запуск при входе зависит от настроек автозагрузки Windows.
- SSH-консоль освобождает слот сеанса при отключении.

# ServerDeck 0.3.9

- Вход в аккаунт через VK ID в системном браузере Windows и Android.
- Совместимость с аккаунтами синхронизации без email; идентичность аккаунта
  и устройства проверяется по прежним обязательным полям протокола.
- Первый подписанный Android APK для arm64-v8a и x86_64, Android 7.0 и новее.

В настройках «Аккаунт и синхронизация» укажите `https://serverdeck.ru`, включите
синхронизацию и выполните вход через VK. Подтвердите совпадающий код устройства
в браузере и вернитесь в приложение. На втором устройстве используйте тот же
аккаунт VK; для существующего хранилища потребуется ваш код восстановления.
SSH-пароли и приватные ключи передаются в зашифрованном виде; вход VK не заменяет
расшифровку хранилища.

Windows: установщик и подписанный каталог обновлений. Android: отдельный APK,
подписанный постоянным ключом Android; механизм обновлений Windows к нему не применяется.
Сборки и unit-проверки не подтверждают полный вход VK и обмен между реальными устройствами.
